# PISÁO Experience Visual System — Phase V2

This phase extends the menu visual language across the main public experience.

## Surfaces
- Home: atmosphere and terrace storytelling.
- Gallery: editorial masonry-like composition and cleaner visual filtering.
- Reservations: aspirational split layout with high-clarity form styling.
- Events: current-state-safe agenda that never promotes expired placeholder events as upcoming.

## Principles
1. Use real PISÁO photography already present in the repository.
2. Food photography sells appetite; terrace photography sells occasion.
3. Conversion CTAs remain visible but subordinate to imagery and hierarchy.
4. Do not invent active events, availability, promotions, or confirmations.
5. Past events may remain addressable by URL but are not presented as upcoming agenda items.
6. Keep image loading responsive through `next/image`, accurate `sizes`, and critical-image priority only.
